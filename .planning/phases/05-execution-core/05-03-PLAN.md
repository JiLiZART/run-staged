    4. Internal `tasks_for_group(matched: &MatchedGroup, git_root: &Path) -> Result<Vec<Task>, AppError>`:
       - For each `MatchedPattern` in `matched.patterns`:
         - For each `command_str` in `pattern.commands`:
           - If `matched.group.per_file == true`: for each file in `pattern.files`, call `build_argv(command_str, &[file.clone()], group.path_format, git_root)` → push one Task per file.
           - Else (batch): call `build_argv(command_str, &[], group.path_format, git_root)` first to get the bare argv, measure its length, then call `chunk_files(&bare_argv, &pattern.files)` → for each chunk, call `build_argv(command_str, chunk, group.path_format, git_root)` and push one Task per chunk.
           - Skip if `pattern.files.is_empty()` (D-27 — defensive; matcher already drops these).

    5. Internal `execute_group_parallel(tasks, cancel, continue_on_error) -> Vec<CommandOutcome>`:
       - `let mut set = JoinSet::new();` for each task spawn `set.spawn(async move { run_one(task, cancel).await })`.
       - Loop `while let Some(joined) = set.join_next().await { ... }`:
         - On JoinError, push a synthetic `CommandOutcome::Failure { exit_code: -1, stderr: "task panicked: {e}".into_bytes(), .. }`.
         - On `outcome.is_failure() && !continue_on_error`: `cancel.store(true, Ordering::Relaxed)` to signal siblings.
         - Push outcome.
       - Return outcomes.

    7. Public function:
       ```rust
       /// Execute all matched groups. Outer loop is sequential across groups (D-14, Pitfall 7).
       /// Inner dispatch obeys each group's `execution_order`. Returns all outcomes
       /// regardless of failures — caller checks `is_failure()` to decide restore.
       pub async fn execute_all(
           matched_groups: &[MatchedGroup<'_>],
           config: &Config,
           git_root: &Path,
       ) -> Vec<CommandOutcome> {
           let mut all_outcomes = Vec::new();
           for matched in matched_groups {
               let cancel = Arc::new(AtomicBool::new(false));
               let tasks = match tasks_for_group(matched, git_root) {
                   Ok(t) => t,
                   Err(e) => {
                       // build_argv shlex failure — surface as a synthetic Failure for this group.
                       all_outcomes.push(CommandOutcome::Failure {
                           group: matched.group.name.clone(),
                           pattern: String::new(),
                           command: String::new(),
                           argv: vec![],
                           file_count: 0,
                           duration: Duration::ZERO,
                           exit_code: -1,
                           stdout: vec![],
                           stderr: format!("argv build failed: {e}").into_bytes(),
                       });
                       if !config.continue_on_error { break; }
                       continue;
                   }
               };
               if tasks.is_empty() { continue; }  // empty pattern files — D-27 defensive.
               let group_outcomes = match matched.group.execution_order {
                   ExecutionOrder::Parallel => {
                       execute_group_parallel(tasks, cancel, matched.group.continue_on_error).await
                   }
                   ExecutionOrder::Sequential => {
                       execute_group_sequential(tasks, cancel, matched.group.continue_on_error).await
                   }
               };
               let group_had_failure = group_outcomes.iter().any(CommandOutcome::is_failure);
               all_outcomes.extend(group_outcomes);
               if group_had_failure && !config.continue_on_error {
                   break; // D-14 cross-group gate
               }
           }
           all_outcomes
       }
       ```

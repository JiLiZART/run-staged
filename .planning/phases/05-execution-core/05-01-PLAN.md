       ```rust
       /// A single pattern within a group plus the files that matched it and the commands to run.
       #[derive(Debug, Clone)]
       pub struct MatchedPattern {
           pub pattern: String,         // original pattern string (e.g., "*.ts")
           pub commands: Vec<String>,   // command strings from config (e.g., ["eslint --fix"])
           pub files: Vec<PathBuf>,     // matched files for this pattern
       }

       /// A group's matched patterns, with the group reference for execution settings.
       #[derive(Debug, Clone)]
       pub struct MatchedGroup<'a> {
           pub group: &'a Group,                // borrowed; executor reads timeout/exec_order/etc.
           pub patterns: Vec<MatchedPattern>,   // only patterns with >=1 matched file (D-27)
       }
       ```

    3. Internal helper `build_globsets(patterns: &[&str]) -> Result<(GlobSet, GlobSet, bool), AppError>`:
       - Iterate input patterns; for each, strip a leading `!` to determine include vs exclude.
       - Auto-prefix `**/` if the (post-strip) pattern contains NO `/` character (D-02 matchBase).
       - Build with `GlobBuilder::new(&normalized).case_insensitive(false).build()` (D-04 case-sensitive default).
       - Map `globset::Error` to `AppError::ConfigInvalid(format!("invalid glob pattern {raw:?}: {e}"))`.
       - Return tuple `(include_set, exclude_set, has_any_include_patterns: bool)`.

    4. Public function:
       ```rust
       pub fn match_files<'a>(
           config: &'a Config,
           files: &[PathBuf],
       ) -> Result<Vec<MatchedGroup<'a>>, AppError>
       ```
       Algorithm:
       - For each `group` in `config.groups`:
         - For each `(pattern_str, commands)` in `group.patterns`:
           - Build globsets from the SINGLE pattern string treated as a slice of one (`&[pattern_str.as_str()]`).
           - If `has_any_include_patterns == false` (the single pattern was a `!`-only string): return `Err(AppError::ConfigInvalid(format!("group '{}' pattern '{}' has only negation — nothing can match", group.name, pattern_str)))`.
           - Filter `files` by `include.is_match(p) && !exclude.is_match(p)`.
           - If matches non-empty, push `MatchedPattern { pattern: pattern_str.clone(), commands: commands.clone(), files: matched }` into the group's pattern list.
         - If the group's pattern list is non-empty, push `MatchedGroup { group, patterns: ... }`.
       - After all groups: if total matched-pattern count across all groups is 0, return `Err(AppError::NoFilesMatched)`. Otherwise return `Ok(matched_groups)`.

       Note on the "only negations across whole group" case: the per-pattern check above catches it because each entry in `group.patterns` is one pattern string. If users want negation, they must combine include + negate in the SAME pattern string (multiple comma-separated patterns are NOT supported in this phase — single string per HashMap key). Document this in a doc comment.

    1. **Update `lib.rs::run()` signature** to accept a bool parameter:
       ```rust
       pub async fn run(unstaged: bool) -> Result<(), AppError>
       ```

    2. **Add conditional branch in `run()`** after opening GitContext:
       ```rust
       let files = if unstaged {
           git_ctx.unstaged_files()?
       } else {
           git_ctx.staged_files()?
       };
       ```
       When `unstaged` is true, skip the `backup()` call — backup saves the staged diff which is irrelevant for unstaged mode. Keep the existing debug output but change the label from "Staged files" to "Files" (or conditionally print "Staged files" vs "Unstaged files").

    3. **Update `main.rs`** to detect --unstaged via `std::env::args()`:
       ```rust
       use std::process;

       #[tokio::main]
       async fn main() {
           let unstaged = std::env::args().any(|a| a == "--unstaged");
           if let Err(e) = fast_staged::run(unstaged).await {
               eprintln!("error: {e}");
               process::exit(1);
           }
       }
       ```
       This is intentionally minimal — Phase 6 replaces this with full clap parsing.

    4. **Add integration test** in `tests/integration_test.rs`:
       - `test_binary_with_unstaged_flag_shows_unstaged_files`: Create a real git repo, commit a file, modify it without staging, run binary with `--unstaged`, assert stderr output contains the modified filename.
       - `test_binary_without_unstaged_flag_shows_staged_files`: Create a real git repo, stage a file, run binary without `--unstaged`, assert stderr output contains the staged filename. (May already exist — check first and skip if covered.)

    Note: The `unstaged_files()` return is allowed to be empty without error (unlike `staged_files()` which returns `AppError::NoStagedFiles`). When `--unstaged` is set with no unstaged changes, the tool should proceed with an empty file list (or print a message and exit 0 — use your judgment, but do NOT return `AppError::NoStagedFiles`).

    IMPORTANT: Do NOT add clap or any argument parsing crate. Use only `std::env::args()`. Phase 6 handles full CLI.

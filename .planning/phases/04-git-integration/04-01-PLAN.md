  <action>
    Create `crates/fast-staged/src/git.rs` with:

    1. `pub struct GitContext` holding a `gix::Repository` field.

    2. `pub fn open() -> Result&lt;Self, AppError&gt;`:
       - Call `gix::discover(".")` per D-01
       - Map any error to `AppError::NotGitRepository`
       - Return `Ok(Self { repo })`

    3. `pub fn git_dir(&self) -> &std::path::Path`:
       - Return `self.repo.git_dir()`

    4. `pub fn staged_files(&self) -> Result&lt;Vec&lt;PathBuf&gt;, AppError&gt;`:
       - Call `self.repo.open_index()` (not `index()` — per Pitfall 2, open_index gives fresh read) per D-02
       - Map error to `AppError::Git(e.to_string())`
       - Get `path_backing()` from the index state
       - Iterate `entries()`, filter `entry.stage() == 0` (only normal staged, not conflict stages 1-3)
       - Convert each entry path via `entry.path(&backing).to_str_lossy()` into `PathBuf`
       - If result vec is empty, return `Err(AppError::NoStagedFiles)` per GIT-07
       - Otherwise return `Ok(files)`

    5. `pub fn unstaged_files(&self) -> Result&lt;Vec&lt;PathBuf&gt;, AppError&gt;`:
       - Use `self.repo.status(gix::progress::Discard)` to create status platform
       - Configure with `.untracked_files(gix::status::UntrackedFiles::None)` — we only want modified tracked files
       - Call `.into_iter(None::&lt;gix::bstr::BString&gt;)` to get the iterator
       - Filter for `IndexWorktree` variant items (index-vs-worktree = unstaged changes)
       - Extract path from each item, convert to PathBuf
       - Return the collected vec (empty vec is ok for unstaged — no error on empty)
       - Note: The exact `gix::status::Item` variant names may need adjustment during implementation. Use `cargo doc --open` on gix to verify the enum shape. The status iterator returns items that include `IndexWorktree` changes for modified-but-not-staged files.

    6. Unit tests in `#[cfg(test)] mod tests` at the bottom of git.rs:
       - Helper `make_real_git_repo(suffix: &str) -> PathBuf` that runs `git init`, sets user.email/user.name config
       - Helper `stage_file(repo: &Path, name: &str, content: &str)` that writes file and runs `git add`
       - Helper `commit_all(repo: &Path, msg: &str)` that runs `git commit -am`
       - All tests must `std::env::set_current_dir` to the temp dir before calling `GitContext::open()` since gix::discover uses CWD
       - Clean up temp dirs after each test

    Important gix API notes from research:
    - Use `gix::bstr::ByteSlice` trait for `.to_str_lossy()` on BStr
    - `entry.path(&backing)` returns `&gix::bstr::BStr`
    - gix 0.81 is already declared in Cargo.toml with default features — keep defaults per Pitfall 8
    - For unborn HEAD repos (no commits), `staged_files()` still works because index entries exist after `git add` regardless of HEAD state

    **parse_toml.rs** — Implement `pub fn parse_toml_file(path: &Path) -> Result<Config, AppError>`:

    1. Read file with `std::fs::read_to_string(path).map_err(AppError::Io)?`
    2. Call `pub fn parse_toml_str(content: &str, source: ConfigSource) -> Result<Config, AppError>` (separate fn for testability without filesystem)
    3. Deserialize content as `RawConfig` via `toml::from_str::<RawConfig>(content).map_err(|e| AppError::ConfigInvalid(format!("{}: {}", path_display, e)))?`
    4. If `raw.patterns` is Some, create a "default" group from it using `defaults::resolve_group()`
    5. For each entry in `raw.groups` HashMap, deserialize `toml::Value` into `RawGroupConfig` via `value.try_into::<RawGroupConfig>().map_err(...)`. Use the HashMap key as group name. Call `defaults::resolve_group()`.
    6. If no groups were created (no patterns anywhere), return `Err(AppError::ConfigInvalid("no patterns defined".into()))`
    7. Build and return `Config` with resolved top-level defaults and `ConfigSource::TomlFile(path)`

    For `parse_toml_str`, accept `source: ConfigSource` parameter so tests can pass a dummy source.

    **parse_json.rs** — Implement `pub fn parse_json_file(path: &Path) -> Result<Config, AppError>`:

    1. Read file with `std::fs::read_to_string(path).map_err(AppError::Io)?`
    2. Call `pub fn parse_json_str(content: &str, source: ConfigSource) -> Result<Config, AppError>`
    3. Parse as `serde_json::Value` first for two-phase detection
    4. Try structured: `serde_json::from_value::<RawJsonConfig>(raw.clone())`
       - If Ok, build Config same as TOML (default group from `patterns`, named groups from `groups` HashMap)
    5. If structured fails, check per D-08 and Pitfall 7: only attempt flat detection if the JSON object has NO keys matching config field names ("timeout", "execution_order", "continue_on_error", "per_file", "patterns"). The exact set of config field names to check: `["timeout", "execution_order", "continue_on_error", "per_file", "patterns"]`.
    6. If flat detection eligible: try `serde_json::from_value::<HashMap<String, Vec<String>>>(raw)`. If Ok, create single "default" group.
    7. If both fail, return `Err(AppError::ConfigInvalid(format!("{}: expected structured config or flat glob-to-commands mapping", path_display)))`
    8. Validate at least one pattern exists, same as TOML.

    Also implement `pub fn parse_package_json_value(value: serde_json::Value, source: ConfigSource) -> Result<Config, AppError>` — this will be used by discover.rs in Plan 02. It takes the already-extracted `"fast-staged"` value and parses it using the same structured/flat logic.

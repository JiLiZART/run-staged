    **discover.rs** — Implement two public functions:

    1. `pub fn find_config_file(start: &Path) -> Result<PathBuf, AppError>`:
       - Per D-10: Walk up from `start` to git repository root. Check all 5 formats per directory before moving to parent. First match wins.
       - Per D-11 priority within each directory: `.fast-staged.toml` > `.fast-staged.json` > `fast-staged.toml` > `fast-staged.json` > `package.json[fast-staged]`
       - Git root detection: Scan for `.git/` directory (NOT using gix — per RESEARCH.md open question 1, use simple `.git/` directory scan for Phase 2). Walk ancestors until `.git/` is found or filesystem root is reached. The git root is the directory containing `.git/`.
       - For `package.json`: read the file, parse as `serde_json::Value`, check if `value.get("fast-staged")` is Some. Only return the package.json path if the key exists.
       - If walk completes without finding any config, return `Err(AppError::ConfigNotFound)`

       Priority constant:
       ```rust
       const CONFIG_FILES: &[&str] = &[
           ".fast-staged.toml",
           ".fast-staged.json",
           "fast-staged.toml",
           "fast-staged.json",
       ];
       ```

    2. `pub fn load_config(explicit_path: Option<&Path>) -> Result<Config, AppError>`:
       - Per D-12: If `explicit_path` is Some:
         - Check file exists. If not, return `Err(AppError::ConfigNotFound)`
         - Determine format from extension: `.toml` -> `parse_toml_file`, `.json` -> `parse_json_file`
         - For `package.json` specifically: read, extract `"fast-staged"` key, call `parse_package_json_value`
         - For any other extension, try TOML first then JSON
         - Wrap source as `ConfigSource::Explicit(path)`
       - If `explicit_path` is None:
         - Call `find_config_file(&std::env::current_dir().map_err(AppError::Io)?)` to get the config path
         - Determine format from filename/extension and parse accordingly
         - Set ConfigSource based on the file (TomlFile, JsonFile, or PackageJson)

       Helper to determine format and parse:
       ```rust
       fn parse_config_at(path: &Path, source: ConfigSource) -> Result<Config, AppError> {
           let filename = path.file_name().and_then(|n| n.to_str()).unwrap_or("");
           if filename == "package.json" {
               let content = std::fs::read_to_string(path).map_err(AppError::Io)?;
               let pkg: serde_json::Value = serde_json::from_str(&content)
                   .map_err(|e| AppError::ConfigInvalid(format!("{}: {}", path.display(), e)))?;
               let fs_value = pkg.get("fast-staged")
                   .ok_or_else(|| AppError::ConfigInvalid(format!("{}: missing 'fast-staged' key", path.display())))?;
               parse_json::parse_package_json_value(fs_value.clone(), source)
           } else if filename.ends_with(".toml") {
               parse_toml::parse_toml_file(path)
           } else {
               parse_json::parse_json_file(path)
           }
       }
       ```

       After parsing, override the `source` field on the returned Config to use the correct ConfigSource variant (Explicit for --config, auto-detected type for discovery).

    pub mod config;
    pub use error::AppError;

    pub async fn run() -> Result<(), AppError> {
        // Phase 2: Load config (auto-discover, no --config flag yet — Phase 6 adds CLI)
        let config = config::load_config(None)?;

        // Debug output until TUI is built (Phase 8)
        eprintln!("Loaded config from {:?}", config.source);
        eprintln!("Groups: {}", config.groups.len());

    }
